# 📌 Техническое задание

## Проект: Сервис анализа персональных социальных графов

### 🎯 Цель проекта
Создание веб-приложения для визуализации и анализа персональных социальных графов, где каждый пользователь может создавать, редактировать и анализировать графы, содержащие его контакты, объединённые в логические группы (работа, учёба и пр.).

---

## 🔧 Технологии

- **Backend:** Go (REST API, Fiber / Echo / Gin)
- **Frontend:** React + TypeScript
- **База данных:** MongoDB
- **Аутентификация:** JWT / OAuth2 (по выбору)
- **Развёртывание:** Docker / Docker Compose

---

## 🔐 Пользователи

### Регистрация и вход
- Регистрация нового пользователя по почте и паролю  
- Авторизация (с получением JWT-токена)  
- Профиль пользователя: имя, email, аватар (опционально), статистика

---

## 🔄 Функциональность

### 1. Граф пользователя
- У каждого пользователя — свой отдельный граф

**Узлы двух типов:**

- **Контакт (ContactNode):**  
  `id`, `name`, `phone`, `email`, `social_links` (массив ссылок), `comment`

- **Группа (GroupNode):**  
  `id`, `label`, `comment`

**Рёбра:**
- Связывают контакты между собой и с группами  
- Поля: `id`, `source`, `target`, `label`, `color`, `size`

---

### 2. Работа с графом
- Создание / редактирование / удаление узлов
- Связывание узлов между собой
- Загрузка графа целиком
- Возможность фильтрации (например, показать только одну группу)
- Автоматическое сохранение позиции узлов (`x`, `y`) и масштаба

---

### 3. Профиль пользователя
- Общее количество контактов
- Количество групп
- Количество связей
- Группировка контактов по группам (например: "Компания Х — 5 человек")
- Визуализация распределения по группам (Pie chart)

---

## 🧩 Backend: REST API

### Аутентификация
- `POST /auth/register` — регистрация
- `POST /auth/login` — вход
- `GET /auth/profile` — получить информацию о пользователе

### Работа с графом
- `GET /graph` — получить весь граф пользователя
- `POST /nodes` — создать узел (контакт или группу)
- `PUT /nodes/{id}` — редактировать узел
- `DELETE /nodes/{id}` — удалить узел
- `POST /edges` — создать связь
- `PUT /edges/{id}` — редактировать связь
- `DELETE /edges/{id}` — удалить связь

---

## 🎨 Frontend: React SPA

### Страницы:
- **Login / Register**
- **Главная (Dashboard):**
  - Статистика профиля
  - Быстрые действия (добавить контакт, группу)
- **Редактор графа:**
  - Визуальный редактор (D3.js, Sigma.js или Cytoscape.js)
  - Возможность перемещать, масштабировать, выделять узлы
  - Формы добавления/редактирования узлов и рёбер
- **Контакты по группам:**
  - Список всех групп
  - Просмотр контактов в группе
