# Backend

Писать серверную логику на Go было решено по причине некоторого опыта в разработке на Go и личной симпатии

## Используемые библиотеки

1. [Gin](https://github.com/gin-gonic/gin) - для разработки API 
2. [mongo-migrate](https://github.com/xakep666/mongo-migrate) - для разработки миграций для Mongo
